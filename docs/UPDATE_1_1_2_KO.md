# 딜나루 1.1.2 — 중고나라만 남기기·JetBrains 가격 수정

2026년 11월 19일 기준. 기존 매물 제목 보정, 검색 결과 전체 최저가, Google AI 공식 가격 수집, 할인 예측 기능은 유지합니다.

## 1. 당근 수집을 다시 확인한 결과와 제거 범위

동일한 공개 수집 방식으로 당근의 robots.txt와 중고거래 검색 페이지를 다시 요청했습니다. 두 주소 모두 **HTTP 403, CloudFront ‘Request blocked’** 응답을 반환했습니다. 매물 HTML을 받은 뒤 파싱에 실패한 것이 아니라, 매물 데이터를 받기 전에 요청이 거부된 상태입니다.

이번 응답만으로 서버의 IP·지역·자동 요청 보호 중 어느 조건이 차단을 유발했는지 단정할 수 없습니다. 정상적으로 수집이 되는 공개 경로를 확보하지 못했으므로 사용자의 요청에 따라 기능을 제거했습니다. 차단을 우회하거나 특정 서버에서 수집된다고 가정한 코드는 넣지 않았습니다.

제거한 부분:

- 수집 출처와 요청 분기, 지역 설정, 관련 환경 변수와 Docker 전달 설정.
- 관리자 출처 선택·지역 입력, 일반 검색 화면 출처 필터·외부 검색 링크·전용 색상.
- 이용약관의 제공 출처 안내와 데모 시세, 게임 상세 응답의 이전 출처 평균 가격.
- 이전 출처의 공개 매물 노출·최저가 비교·통계 집계.

이제 중고마켓은 **중고나라만** 요청하고 보여줍니다. 키워드 검색, 14일 보관 기준, 제목 보정, 가격순 정렬, 검색 결과 전체 최저가·동률 강조는 유지합니다. 중고나라에서도 출처가 접근을 제한하면 HTTP 코드와 실패 단계를 표시합니다.

백엔드 시작과 다음 수집 때 이전에 저장된 당근 출처의 매물 행만 정리합니다. 중고나라 매물·회원·찜·알림·게임은 제거하지 않습니다. 이전 버전 DB의 더는 사용하지 않는 호환 열은 강제로 삭제하지 않아도 실행할 수 있도록 했으며, 새 모델과 API는 그 값을 읽거나 노출하지 않습니다.

## 2. JetBrains의 금액 확인 필요 원인

이전 카탈로그는 `JetBrains Toolbox`라는 제품 안에 유료 All Products Pack 하나만 넣고, 가격을 자동으로 확인하지 않는 참고 항목으로 설정했습니다. 또한 JetBrains 공식 구매 페이지의 초기 본문은 짧은 ‘Store’ 문구뿐이고 실제 가격은 HTML 안의 `productsData` JSON에 들어 있어 본문 검사만으로는 가격을 읽지 못했습니다.

실제로는 다음 두 종류를 구분해야 합니다.

- **Toolbox App**: IDE 설치·업데이트·버전 관리를 하는 무료 앱입니다. 유료 IDE의 라이선스를 제공하는 구독 상품은 아닙니다.
- **All Products Pack**: JetBrains IDE를 묶어 제공하는 별도 유료 구독입니다. 개인용·기업용, 월간·연간, 신규·계속 구독에 따라 요금이 다릅니다.

이번에 공식 페이지 실접속과 파싱으로 확인한 가격:

| 항목 | 금액 | 기준 |
| --- | ---: | --- |
| Toolbox App · 관리 앱 | 무료 | IDE 관리 앱. 유료 IDE 라이선스는 별도 |
| All Products Pack · 개인용 월간 | US$29.90 / 월 | 개인 신규 월간 구독 |
| All Products Pack · 개인용 연간 | US$299 / 년 | 첫해 1년 전체 선결제 금액 |

USD 표시 기준이며 세금·지역·갱신 조건에 따른 최종 금액은 공식 결제 화면에서 확인합니다. 연간 요금의 두 번째·세 번째 가격은 계속 구독 할인액이므로 첫해 가격으로 사용하지 않습니다. 연간 월 환산액도 연간 전체 금액과 구분합니다.

수정한 수집기는 공식 HTML의 JSON을 실행 없이 읽고, 상품 코드 `ALL`, 개인용 `personal`, 통화 `USD`, 월간·연간 구분을 함께 확인합니다. 기업용 가격·AI 부가 상품·다른 IDE·할인용 0원·월 환산액을 대신 가져오지 않습니다. 원문 구조가 달라지거나 가격 후보가 충돌하면 마지막 확인 금액과 날짜를 유지합니다.

기존 가격 미확인 행은 같은 ID로 갱신하며 Toolbox 무료 앱과 연간 요금제 2개를 추가합니다. 기존 회원 정보를 초기화하지 않습니다.

## 3. 적용 순서

1. 현재 프로젝트 폴더와 DB를 백업합니다. 실제 `.env`, `backend/.env`, `frontend/.env`는 유지합니다.
2. 개발 서버를 사용 중이라면 두 터미널에서 `Ctrl+C`로 중지합니다.
3. 수정본 ZIP의 `dealnaru` 안 파일을 기존 프로젝트에 반영합니다. 실제 환경 설정을 `.env.example` 내용으로 바꾸지 마세요.
4. 백엔드를 기존 가상환경에서 다시 실행합니다.

   ```powershell
   cd backend
   venv\Scripts\Activate.ps1
   uvicorn app.main:app --reload
   ```

5. 프런트를 다시 실행합니다.

   ```powershell
   cd frontend
   npm run dev
   ```

6. 브라우저를 새로고침합니다. 중고마켓에는 중고나라만 남고, JetBrains 상세에는 무료 앱·월간·연간 가격이 표시됩니다.
7. 관리자에서 중고 매물 재수집과 공식 혜택 갱신을 필요에 따라 실행합니다. 자동 수집 설정과 중고나라 접근 제한 처리는 기존과 같습니다.

추가 패키지나 새 환경 변수는 필요하지 않습니다. 이전 지역 설정 값이 실제 `.env`에 남아 있어도 더는 사용하지 않습니다. 이를 삭제해도 됩니다.

Docker로 운영 중이면 백업과 소스 반영 후 `docker compose up -d --build`를 실행합니다. DB 볼륨은 유지합니다. **`app.seed --reset` 또는 `docker compose down -v`를 실행하지 마세요.**

1.0에서 바로 올린다면 [기본 업그레이드 안내](UPGRADE_1_1_KO.md)의 운영·개인정보 설정도 함께 확인하세요.

## 4. 확인 범위

- 전체 API·회귀 테스트 **169개 통과**, 프런트 프로덕션 빌드 성공.

- JetBrains 월간 $29.90, 연간 $299, Toolbox App 무료는 공식 페이지에서 실제 파싱을 확인했습니다.
- 테스트는 중고나라 전용 요청, 이전 출처의 화면·비교 제외, 선택적 데이터 정리, 기존 DB의 호환 열, JetBrains 상품·대상·통화·기간·신규 가격 구분과 가격 충돌 처리를 검사합니다.
- 브라우저 미리보기 연결 서비스가 없어 실화면 검증은 진행하지 못했습니다. 프런트 빌드와 API·회귀 검사 결과는 함께 제공한 소스의 테스트로 확인할 수 있습니다.
- 운영 서버·사용 중인 회원 DB에 직접 접속하거나 배포한 작업은 아닙니다. 수정본을 적용하고 백엔드·프런트를 함께 재시작해야 합니다.
