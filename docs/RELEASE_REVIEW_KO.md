# 딜나루 1.0 최종 검증

기준은 첨부한 딜나루 5.4 소스입니다. 2026년 11월 18일에 프로젝트의 원본 및 운영 데이터와 분리한 검증 환경을 사용했습니다.

| 범위 | 확인 결과 |
|---|---|
| 자동 회귀 | SQLite 110개, PostgreSQL 16.2의 별도 검증 DB 110개 통과. 가격 정책, 수집 변환, 이력 작업, 프로그램 요금제, 권한 및 인증 검사를 포함 |
| 브라우저 | Chromium에서 홈 검색, 게임 상세의 현재가·이력·상점 링크, 프로그램 결제 주기, 중고 검색, 약관 링크와 상세 주소의 직접 접속·새로고침 확인 |
| 사용자 흐름 | 메일 전송을 대체한 검증 환경에서 약관 동의, 가입, 링크 인증, 로그인, 찜, 목표가 0원 저장, 알림함, 일반 계정의 관리자 접근 차단, 로그아웃 확인 |
| 작은 화면 | 390px 너비에서 홈, 게임·프로그램·중고 목록, 약관, 로그인 화면의 가로 넘침 검사 통과 |
| 운영 구조 | Compose 구성 검사, Caddy 구성 해석 검사, Caddy → FastAPI → PostgreSQL을 거치는 검증용 HTTPS 상태 조회, PostgreSQL 덤프의 별도 DB 복원 확인 |
| 패키지 | 백엔드 운영 요구사항 pip-audit 및 프런트 운영 패키지 npm audit --omit=dev에서 알려진 항목 0건. 전체 프런트 검사에는 빌드 도구의 간접 의존성 관련 경고가 남아 있음 |
| 코드 품질 | 프런트 ESLint와 운영 빌드 통과. 격리된 테스트 DB로 실행하도록 보강 |

## 개선 내용

- 읽기 전용 목록에서는 과거 가격 전체를 읽지 않고 현재 스냅샷만 조회합니다. 상세 화면의 이력과 예측은 기존 자료를 사용합니다.
- 서버가 세션 토큰의 해시를 보관합니다. 운영 쿠키에 Secure, HttpOnly, SameSite를 적용하고 로그아웃과 관리자 비밀번호 재설정에서 서버 세션을 종료합니다. 로그인 시 이전 브라우저 저장소의 토큰을 사용하지 않습니다.
- 신규 비밀번호는 Argon2id로 저장합니다. 기존 bcrypt 계정은 정상 로그인할 때 안전하게 전환할 수 있는 경우 새 형식으로 갱신합니다.
- 반복 인증 요청, 다른 사이트에서 온 쓰기 요청과 잘못된 입력을 검사합니다. 입력 오류에 비밀번호 값을 돌려주지 않고, 토큰은 새 인증 링크의 URL 프래그먼트에 담아 브라우저가 페이지를 처음 열 때 서버 주소로 보내지 않습니다.
- 운영에서 가격 모의 변경, 수동 가격 덮어쓰기, 전체 수집 자료 초기화와 개발 API 문서를 사용하지 않습니다. 운영 API는 한 프로세스에서 갱신 작업을 함께 실행합니다.
- 회원 가입에 이용약관 확인을 추가하고, 정책 공개 페이지에 운영자·문의와 호스팅 조건을 설정할 수 있게 했습니다. 중고 매물 응답에서 판매자 필드를 공개하지 않습니다.
- 하단 저장소 링크는 승인된 실제 운영 URL이 필요합니다. 첨부 코드에는 해당 URL이 없어서 임의 주소를 넣지 않았습니다. Git 저장소를 공개하거나 사이트를 배포하는 행위는 이 검증에 포함하지 않았습니다.

## 공개 서버에서 확인할 항목

시험에서는 제어 가능한 합성 데이터와 메일 대체 전송을 사용했습니다. 실제 Windows DB를 이전하지 않았으며, Docker 컨테이너의 설치 및 운영 이미지 기동, 공개 도메인 TLS, 실제 Resend 수신, 사용자 발급 키를 사용한 외부 수집 전 범위 및 운영 갱신 한 주기는 실제 서버 준비 후 확인해야 합니다. 브라우저의 검증용 인증서를 실제 서비스에서 예외로 허용하지 않습니다.

공개용 ITAD 데이터 사용 범위와 중고나라 매물 재사용 조건을 먼저 확인합니다. 운영 중고 수집은 초기 설정에서 꺼져 있습니다. 운영 호스팅과 메일 정보, 백업 보관 기간으로 처리방침을 완성하고 휴대폰 데이터 통신 또는 다른 PC에서 배포 안내서의 확인 표를 실행합니다.

설치와 도메인 연결: [운영 배포 안내서](DEPLOYMENT_KO.md).
