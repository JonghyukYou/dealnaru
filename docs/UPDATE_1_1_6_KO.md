# 1.1.6 관리자 중고 매물 관리 · 찜 알림 가격 테스트

## 중고 매물과 키워드 삭제

중고 거래 화면에 관리자 전용 **관리자 편집**을 추가했습니다. 일반 회원과 비로그인 이용자에게는 편집 기능이 보이지 않으며 서버도 관리자 권한을 검사합니다.

- 각 키워드 옆 **삭제**는 그 키워드와 정확히 일치하는 수집 매물을 삭제하고 탭을 제거합니다. 예를 들어 소닉으로 수집한 행을 삭제해도 닌텐도로 수집한 정상 매물은 보존합니다. 전체 탭은 삭제할 수 없습니다.
- 각 카드의 **수집 매물 삭제**는 해당 매물 한 건을 삭제합니다.
- 삭제한 키워드와 매물 URL은 재수집 제외 기록을 남겨 같은 결과가 다음 수집에서 돌아오지 않게 합니다. 이미 진행 중이던 수집이 늦게 저장한 행도 공개 목록·탭·최저가 계산에서 제외합니다.
- **재수집 제외 목록 → 재수집 허용**으로 다시 수집할 수 있게 합니다. 삭제한 본문 자체를 복원하는 기능은 아니므로 허용 후 다시 수집해야 합니다.
- 이 기능은 딜나루에 저장된 사본을 관리합니다. 중고나라 원본 글은 변경하지 않습니다.

업데이트 설치 자체가 소닉·세키로를 자동 삭제하지는 않습니다. 적용 후 관리자 편집에서 두 키워드의 삭제를 선택하면 됩니다. 삭제 전 서버 DB 백업은 적용기가 생성합니다.

## 운영 관리자용 가격 테스트

운영 배포에서 숨기던 예전 수동 가격 덮어쓰기 대신, **찜 알림 · 가격 테스트**를 별도로 추가했습니다. 기존 개발용 API를 공개하지 않습니다.

1. 알림을 받을 계정으로 게임을 찜하고 목표가와 알림 받기를 저장합니다.
2. 관리자 화면에서 게임과 원화 관측 가격이 있는 구매처를 선택합니다.
3. 목표가 이하인 테스트 가격과 자동 해제 시간을 선택합니다. 예: Baba Is You 목표가 12,000원, Steam 테스트 가격 10,000원.
4. 알림 받을 이메일은 비워두면 현재 관리자 본인입니다. 다른 테스트 계정의 가입 이메일을 입력하면 그 계정 한 명에게만 시험합니다. 다른 찜 이용자에게 테스트 알림을 보내지 않습니다.
5. **테스트 이메일도 보내기**는 선택 사항이며 기본값은 꺼짐입니다. 켜도 기존 계정의 메일 인증·메일 수신 설정을 따릅니다. 사이트 알림과 이메일의 제목·내용에는 테스트용임을 명시합니다.
6. 적용 결과에 알림 생성 수와 메일 성공·실패 수가 표시됩니다. 찜이 없거나 알림이 꺼져 있거나 목표가 조건을 충족하지 않으면 알림이 없는 이유를 보여줍니다.
7. **테스트 해제 · 실제 가격으로**를 누르거나 설정 시간이 지나면 테스트 표시를 종료합니다. 기본은 한 시간 후 자동 해제이며 15분·30분·2시간도 고를 수 있습니다.

실제 가격 스냅샷을 수정하거나 비활성화하지 않습니다. 테스트는 별도 테이블에 저장하고 화면에서 해당 구매처의 표시 가격에만 적용합니다. 테스트 중 실제 수집이 진행되면 실제 가격은 계속 저장됩니다. 해제하면 오래된 테스트 전 가격으로 덮어쓰지 않고 그동안 수집한 최신 실제 가격을 표시합니다. 상세·찜은 화면에 돌아오거나 주기적으로 조회할 때 갱신합니다.

## 표시와 분석

- 게임 상세의 적용 안내, 구매처별 가격, 찜 목록, 게임 카드에 테스트용 배지를 표시합니다.
- 가격 그래프의 실제 가격선은 보존하고 테스트 가격은 **주황색 점과 (테스트용)** 라벨로 별도로 표시합니다. 해제·만료 후에도 표시한 테스트 이력은 해당 표시와 함께 남습니다.
- 실제 기간 최저가·할인 횟수·평균 할인율·할인 예측은 실제 관측값만 사용합니다. 오늘의 특가 선정에도 테스트 가격을 사용하지 않습니다.
- 사이트의 테스트 알림 유형은 `TEST_TARGET_PRICE`로 구분하여 실제 목표가 알림의 24시간 중복 방지에 영향을 주지 않습니다. 목표가 검사와 이메일 생성은 실제 수집과 같은 공통 알림 코드를 사용합니다.

## 적용과 검증 범위

운영 DB에 필요한 두 테이블을 추가하며 게임·가격·회원 자료와 .env, 자동 백업 예약을 유지합니다. 이전 1.1.5의 요청 조절·로그 요약 수정도 포함합니다.

격리된 SQLite DB에서 기존 199개와 새 동작 19개를 합한 **218개 테스트**가 통과했습니다. 삭제 범위·권한·재수집 차단·가격 분리·지정 계정 알림·메일 표시·자동 만료·실제 수집 후 해제를 확인했습니다. 프런트엔드 lint와 배포 빌드도 통과했습니다. 실제 운영 PostgreSQL·Resend 전달과 브라우저 렌더링은 이번 환경에서 새로 검증하지 못했습니다. 미리보기 연결이 제공되지 않아 브라우저 화면 검증은 적용 후 확인해야 합니다.
