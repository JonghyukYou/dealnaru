# 딜나루 1.1.1 — 첨부 화면 오류 수정·적용 안내

2026년 11월 19일 기준. 기존 1.1을 사용한 뒤 보고된 매물 제목 오류와 Google AI 가격 누락을 수정했습니다. 중고 수집 실패의 중단 단계와 원인 표시를 보강했습니다.

## 1. 매물 제목이 ‘39,000’처럼 나오던 문제

이전 수집기가 `h3` 같은 제목 태그를 곧바로 상품명으로 사용했습니다. 중고나라 카드에서 가격이 `h3`로 표시되거나 링크에 가격만 있고 상품명이 옆에 있는 경우 가격을 이름으로 저장할 수 있었습니다. 상품명에 붙은 가격도 분리되지 않았습니다.

수정본은 상품명 필드·제목 속성·유효한 제목·이미지 대체 텍스트·카드 텍스트를 검증하고, 가격·시간·일반 UI 문구를 상품명 후보에서 제외합니다. 원 단위가 생략된 가격도 가격 노드에서 별도로 읽으며 인접한 다른 매물의 금액을 섞지 않습니다.

- `39,000` + `엘든링 PS5` → 제목 **엘든링 PS5**, 가격 **39,000원**.
- `PS4 세키로 팝니다 38,000` → 제목 **PS4 세키로 팝니다**, 가격 **38,000원**.
- `FIFA 17`, `PS4`처럼 상품명에 들어 있는 숫자는 가격과 일치하는 별도 표시가 아니면 제거하지 않습니다.
- 이름을 못 읽은 행은 가격만 제목에 넣어 저장하지 않습니다.

### 이미 잘못 저장된 매물

백엔드 시작 시 기존 중고나라 매물 제목을 자동 점검합니다. 상품명 뒤의 동일 가격은 정리합니다. 제목 전체가 가격뿐이면 원래 이름을 추측할 수 없으므로 행을 삭제하지 않고 `제목 확인 필요`로 표시해 공개 목록·최저가 계산에서 제외합니다.

관리자에서 같은 키워드로 다시 수집하면 같은 매물 URL의 원래 상품명을 갱신하고 판매중 상태로 되돌립니다. 매물 ID는 유지합니다. 출처가 접근을 막으면 상품명을 복원할 수 없으며 그 매물은 복원 대기 상태로 남습니다. 관리자 수집 결과에서 남은 복원 대기 개수를 볼 수 있습니다.

## 2. 중고 수집 안내

현재 버전은 중고나라만 지원합니다. 최신 구성과 변경 이유는 [1.1.2 적용 안내](UPDATE_1_1_2_KO.md)를 확인하세요.

## 3. Google AI 가격이 빈칸이던 문제

공식 페이지의 초기 HTML에는 가격 대신 `<g1-localized-price>`라는 빈 요소가 있었습니다. 브라우저에서 JavaScript가 한국용 공식 가격 JSON을 불러와 금액을 넣는 구조인데, 이전 수집기는 초기 HTML만 읽어 가격이 없다고 처리했습니다.

수정본은 페이지에 연결된 공식 가격 컴포넌트에서 현재 가격 피드 파일명을 찾고, **Google 공식 한국 가격 JSON**을 읽습니다. 국가 `KR`, 통화 `KRW`, 요금제별 정확한 월간 가격 키를 검증합니다. 가격이 바뀌면 다음 갱신에서 해당 공식 값을 사용합니다. JS를 실행하거나 로그인 화면을 우회하는 방식은 사용하지 않습니다.

이번에 공식 페이지 → 연결된 JS → 공식 한국 가격 JSON → 요금제 파서까지 실제 요청으로 확인한 결과:

| 요금제 | 월 정기 요금 |
| --- | ---: |
| Google AI Plus | 7,500원 |
| Google AI Pro | 29,000원 |
| Google AI Ultra 5x | 119,000원 |
| Google AI Ultra 20x | 300,000원 |

공식 첫 화면의 Ultra ‘최저 119,000원’은 기본 5배 단계에 대응합니다. 상세 비교표에는 20배 단계도 따로 있어 구분해 저장합니다. 첫 달 체험·학생 혜택·계정별 프로모션은 정기 요금과 다릅니다.

새 가격과 확인일은 백엔드 시작 시 기존 빈 요금제에도 적용됩니다. 이후 관리자 **공식 혜택 갱신**에서 같은 공식 데이터를 다시 읽습니다. 국가·통화가 다르거나 특정 요금제 값이 없으면 다른 금액을 대신 넣지 않으며 마지막 확인값·날짜를 보존합니다. 자동 확인 실패 사유도 요금제 화면에 표시합니다.

- [공식 한국어 요금 페이지](https://one.google.com/intl/ko_kr/about/google-ai-plans/)
- [이번에 확인한 공식 한국 가격 JSON](https://one.google.com/intl/ALL_kr/about/feeds/pricing_2026_11_16.json)

현재 카탈로그는 제품 20개·요금제 68개입니다. 기존 1.1에서 확인한 54개에 Google AI 4개를 보강해, 이번 작업까지 확인된 값 58개·과거 확인값 9개·당시 금액 미확인 1개로 구분했습니다. 이후 JetBrains 3개 요금제를 공식 가격으로 보강했으며 최신 결과는 [1.1.2 안내](UPDATE_1_1_2_KO.md)를 확인하세요. 모든 출처를 이번에 다시 실접속한 것은 아니며, Google AI 4개는 이번 수정에서 다시 확인했습니다.

## 4. 적용 순서 — 기존 DB 초기화 불필요

1. 현재 프로젝트 폴더와 DB를 백업합니다. 현재 `.env`, `backend/.env`, `frontend/.env`는 유지합니다.
2. 개발 서버라면 두 터미널에서 `Ctrl+C`로 중지합니다.
3. 수정본 ZIP의 `dealnaru` 안 파일을 기존 프로젝트에 반영합니다. 기존 설치 폴더와 실제 환경 설정을 새 예시 파일로 덮어쓰지 마세요. 1.1 대비 추가 설치 패키지·새 환경 변수는 없습니다.
4. 백엔드 터미널에서 현재 가상환경을 활성화하고 재시작합니다.

   ```powershell
   cd backend
   venv\Scripts\Activate.ps1
   uvicorn app.main:app --reload
   ```

5. 프런트 터미널에서 재시작합니다.

   ```powershell
   cd frontend
   npm run dev
   ```

6. 브라우저를 새로고침하고 프로그램·AI → Google AI의 가격이 표시되는지 봅니다.
7. 관리자 → 중고마켓에서 이전 키워드를 다시 수집합니다. 제목 뒤 가격은 이미 자동 정리되며, 가격만 제목으로 저장됐던 매물은 재수집에 성공해야 원래 상품명으로 돌아옵니다.

Docker 운영 중이라면 백업·소스 반영 후 프로젝트 폴더에서 `docker compose up -d --build`로 재생성합니다. `.env`와 DB 볼륨을 유지합니다.

**`app.seed --reset`이나 `docker compose down -v`는 실행하지 마세요.** 이 수정에 필요한 작업이 아니며 기존 데이터를 지울 수 있습니다. 1.0에서 바로 올리는 경우에는 [1.1 적용 안내](UPGRADE_1_1_KO.md)의 초기 운영 설정도 함께 확인하세요.

## 5. 검증 범위

- API·회귀 테스트 155개 통과.
- 프런트 프로덕션 빌드 성공.
- 가격이 제목 태그에 있는 경우, 상품명이 링크 옆에 있는 경우, 가격·제목 분리, 기존 손상 행 정리·재수집 복원, Google 동적 공식 피드·국가·통화·가격 키 검증, 수집 단계별 403·시간 초과 진단을 검사했습니다.
- Google AI 4개는 전체 수집 경로에서 실제 공식 금액 파싱을 확인했습니다.
- 중고나라은 이 환경에서 검색 요청이 차단돼 실제 최신 매물 HTML 수집 성공은 검증하지 못했습니다. 매물 파서 회귀 검증은 첨부 화면의 문제를 재현한 합성 HTML로 수행했습니다.
- 미리보기 연결 서비스가 없어 브라우저 실화면 검증은 하지 못했습니다. 운영 서버나 기존 회원 DB에 직접 접속·변경하지 않았습니다.
