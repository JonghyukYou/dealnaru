# 딜나루 · DealNaru

게임 할인 정보, 프로그램·AI 요금제와 중고 게임 매물을 한곳에서 살펴보는 웹 서비스입니다.

**사이트:** [https://dealnaru.life](https://dealnaru.life)

## 주요 기능

- **게임 가격 비교** — 게임을 검색하고 Steam·Epic Games Store 등 구매처별 현재 가격과 할인율을 비교합니다.
- **가격 이력과 할인 예측** — 수집한 가격 이력을 그래프로 확인하고, 과거 할인 주기를 바탕으로 다음 할인 시점과 할인율을 추정합니다.
- **찜과 목표가 알림** — 관심 게임을 찜하고 목표 가격을 설정하면 조건 충족 시 사이트 알림과 이메일을 받을 수 있습니다.
- **프로그램·AI 혜택 조회** — 공식 요금제, 할인과 교육 혜택을 비교합니다.
- **중고 거래 검색** — 중고나라 수집 매물을 키워드별로 검색하고 가격을 비교한 뒤 원본 게시글로 이동합니다.
- **관리자 도구** — 자동 갱신 일정과 수집 로그를 관리하고, 잘못 수집한 매물·키워드를 삭제하거나 테스트 가격으로 찜 알림을 확인합니다.

## 이용 방법

1. 사이트에서 게임, 프로그램·AI 또는 중고 거래를 선택해 검색합니다.
2. 게임 상세에서 구매처별 가격과 가격 이력을 확인합니다.
3. 회원가입과 이메일 인증 후 관심 게임을 찜하고 목표 가격과 알림 수신 여부를 저장합니다.

## 데이터 안내

- 가격과 혜택은 수집 시점 기준이며 외부 서비스의 응답·접근 제한에 따라 갱신이 지연될 수 있습니다. 최종 가격과 구매 조건은 구매처에서 확인해 주세요.
- 할인 예측은 수집 이력에 기반한 추정값이며 실제 할인 일정을 보장하지 않습니다.
- 중고 최저가는 검색 조건에 맞는 수집 매물 기준입니다. 배송비, 플랫폼, 구성품과 상품 상태를 함께 확인해 주세요.
- 관리자 테스트 가격은 **테스트용**으로 표시하며 실제 최저가 통계와 할인 예측에 포함하지 않습니다.
